    E.4 The "what would I show my CTO" deliverables

    After 8-10 weeks of work, the demo should answer five questions:

    1. What does the agent actually do? — one user-visible workflow, end-to-end.
    2. How do we know it works? — eval numbers on a documented golden set.
    3. What does it cost per user per month? — token cost + memory cost + observability cost.
    4. What's the blast radius if it goes wrong? — sandbox, permissions, HITL gates.
    5. What's our exit plan if a vendor changes? — abstractions over MCP/A2A so a memory provider swap is one config change.
